# Contributing

Use a short branch and submit a pull request against `main`. Describe the user-visible behavior and validation. Add meaningful tests for algorithm, persistence or synchronization changes; keep pure domain code in `Packages/WristGroveCore`.

Run the core tests and Apple build checks described in `docs/DEVELOPMENT.md`. Device-only checks must be marked as verified or pending, with device/OS and build recorded. Never put personal health samples, signing material or credentials in issues, fixtures, logs or commits. Use synthetic fixtures.

Preserve original sample timestamps, missing-data states and demo/real separation. Do not introduce a medical claim or a precise stress/recovery score without a separately reviewed evidence and validation plan.

Contributions are licensed under Apache-2.0. Any copied third-party code needs a pinned source, compatible license and retained attribution. Do not copy competitor artwork, branding or unlicensed public source.
